# Tasks

Task plans, investigations, and task-scoped audits live here.

## How To Use

- Start with the highest active version folder for current work.
- Treat task-plan files as executable implementation plans.
- Move retrospectives and postmortems to `docs/archive/` when they stop functioning as active task inputs.

## Contents

- version folders such as `12.0/`, `10.0/`, `8.0/`
- `11.0-closed/`: closed task-plan set kept for reference
- `tech-debt/`: debt-oriented planning and evaluation notes

# Context Alt Text Plugin (Monorepo Workspace)

This directory holds the greenfield WordPress plugin implementation. The code here is the canonical source — LocalWP or other dev environments should symlink to this folder.

## LocalWP Symlink

From the LocalWP site folder (usually `~/Development/wp-context-alt-text/app/public/wp-content/plugins`):

```bash
rm -rf context-alt-text
ln -s ../../../../../context-alt-text/apps/wp-context-alt-text context-alt-text
wp plugin activate context-alt-text
```

Any assets or build artifacts generated by the plugin (e.g., `dist/`) should remain inside this directory so they are versioned with the rest of the project.

# Context Alt Text Plugin (Monorepo Workspace)

This directory holds the canonical WordPress plugin implementation. LocalWP or other dev environments should symlink to this folder when developing the plugin.

## LocalWP Symlink

From the LocalWP site folder (usually `~/Development/wp-context-alt-text/app/public/wp-content/plugins`):

```bash
rm -rf context-alt-text
ln -s ../../../../../context-alt-text/apps/wp-context-alt-text context-alt-text
wp plugin activate context-alt-text
```

Any assets or build artifacts generated by the plugin (e.g., `dist/`) should remain inside this directory so they are versioned with the rest of the project.

## Feature Flags

Two feature flags ship with the scaffold and are disabled by default:

- `CAT_ENABLE_ABILITIES` — Enables the Abilities registrar (post-MVP).
- `CAT_ENABLE_MCP` — Enables the MCP server adapter (post-MVP).

Override them via `wp-config.php` or WordPress filters (`cat_enable_abilities`, `cat_enable_mcp`).

## First-Run Scan

Activation triggers a first-run scan that computes the initial count of attachments missing alt text and schedules a cron event for follow-up scans. The dashboard renders the MVP accessibility status line using these counts.

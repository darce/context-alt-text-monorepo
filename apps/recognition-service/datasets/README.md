# Dataset Utilities

This directory contains scripts for dataset creation and management.

## Scripts

### `make_micro_set.py`

Creates micro datasets for testing and development purposes.

## Usage

Run from the project root directory:

```bash
python datasets/make_micro_set.py
```

## Output

Generated datasets are stored in the `datasets/micro/` directory.

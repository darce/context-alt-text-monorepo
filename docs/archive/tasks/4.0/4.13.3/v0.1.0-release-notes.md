# Release Notes: v0.1.0 Sovereign Cluster

This release marks the first stable milestone of the Context Alt Text monorepo, achieving the **Sovereign Cluster** architecture.

## Primary Objective: Sovereignty
The WordPress plugin now maintains a local projection of identity clusters, removing the hard runtime dependency on backend media URLs.

## Key Features
- **Sovereign Local Projection**: PHP-side database (`wp_acx_clusters`, `wp_acx_identity_members`) persists cluster state.
- **Snapshot Synchronization**: Batch projection from Backend via the `cluster-snapshot` API.
- **Curation-First Integrity**: User decisions in WordPress are ground truth and preserved across sync cycles.
- **Local Read Path**: Admin UI renders from local DB with `acx://` URI indirection for media.

## Breaking Changes
- **`thumbnail_url` Deprecation**: The backend-provided `thumbnail_url` and `cluster_thumbnails` fields have been removed. Clients must now resolve thumbnails locally from WordPress media utilizing `attachment_id` and `bbox`.

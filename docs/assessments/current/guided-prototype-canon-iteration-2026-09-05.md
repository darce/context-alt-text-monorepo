## Screen A — Reset overlay (GP-CANON-01, 02)

Before: confirm button had an undefined class (`--danger`), so it rendered as a bare
text button and Cancel (secondary) was the most prominent control. Dialog portals to
`document.body`, so guided-page focus rings never applied. Canon: INT-09 (destructive
action must be visibly distinct), A11Y-07 (visible focus on every control).

```
┌─ Reset this practice? ───────────────────────────────┐
│ This clears the saved practice decisions and any     │
│ pending description edit, then restores the original │
│ safe example. No WordPress data is written.          │
│                                                      │
│                 [ Cancel ]  [█ Reset practice █]      │
│                  secondary    danger (red fill)      │
│                             ╔═ focus ring 2px ═╗     │
└──────────────────────────────────────────────────────┘
```

After: `.acx-button--danger` (`--acx-color-danger` / `-hover`) and `.acx-button:focus-visible`
are defined globally in `_roster.scss`; the ring now shows inside the portal.

## ch-intro — Personalized connection requests {#ch-intro}

**Counter-default:** Do **not** personalize every connection request. Many decision-makers **hate** salesy notes and reject them; bulk of accepts came from **blank/minimal** requests.

| Prospect type | Connect-note rule |
|---|---|
| Most IC / mid-level / large networks | **Bare request** — no note |
| Directors, C-level, owners | **Short non-pitch note** — reason to accept only |
| Very senior + cold | **Warm first**: connect peers → engage posts → then request |

**Minimal senior note:**

```
Hi Sally,

I’d love to connect,

Kind Regards,
Dan
```

**Never** pitch in the note. **After personalized note accepted:** ~9/10 won’t reply to the note (now first message). Next touch: **audio or video**, not another written line.

| Observable situation | Rule |
|---|---|
| Default “always add a note” | Prefer bare request except senior/shielded |
| Note would be a pitch | Drop note or pure connect intent only |
| Senior accepted note, silent | Switch format (audio/video) |

## ch-1 — Motivation to message {#ch-1}

**Mantra:** People **need and want** what you sell; worst case = not interested now; each message can open the next big deal. Under-messaging is as common as bad messaging—if you can help, send.

## ch-2 — The prospecting maze {#ch-2}

**Prospecting maze:** each buyer has doors (phone, email, LinkedIn, events, F2F). Only 1–2 usually reach them; **every maze differs**.

| Observable situation | Rule |
|---|---|
| Phone-only or email-only team | Open LinkedIn door; some never answer cold calls |
| Channel purity war | Use **alongside** (**combo prospecting**), not versus |
| One channel repeatedly dead | Switch door |

## ch-3 — Outbound social selling {#ch-3}

Social selling ≠ only inbound content. **Outbound social selling** = you start conversation after a warm signal (like, comment, share, profile view).

**Path:** publish → spot engager at target account → connect + topic question (not pitch) → rapport → earn intro to real DM. Views are invisible; **likes/comments/shares** are addressable—optimize content for engagement that surfaces people.

## ch-4 — Why aren’t people replying? {#ch-4}

Three killers: (1) **no personalization** (about you not them); (2) **too cold** (no warmth); (3) **format sameness** (~99% written).

**Warm-up:** engage 2–3 of **their** posts with **contributing** comments (not “Great post!”) → connect/engage others at company → share industry-relevant content. **Format interrupt:** audio **30–60s**; video optimal **60–90s** (max ~2 min); eye contact; clean background.

   “The more you make your message about them, the more likely they will be to reply to you.”

## ch-5 — Research, personalisation & relevance {#ch-5}

**Formula:** **R + P × R = Replies** (Research + Personalisation × Relevance).

**Time budget ∝ deal value** — don’t over-research low ACV.

| Layer | Sources | When |
|---|---|---|
| 1 Basic | Profile, summary, history, recs, **activity** | Every message |
| 2 Deeper | Company page, company posts, announcements | Mid/enterprise |
| 3 Advanced | Other employees; multi-door people | C-level hard; account map |

Mine **conversation starters** (company similarity, activity, CEO posts, active colleagues)—authentic, not forced namedrops. `{FirstName, Company, Title}` alone is insufficient.

## ch-6 — The one thing to avoid {#ch-6}

**Never pester with the same message type.** Silent after written ≠ written #2–#8 (“just checking…”).

**Cadence:** written → wait **5–7 days** → if silent, **audio or video**. Same-format multi-touch trains ignore and kills trust.

## ch-7 — No one likes spam messages {#ch-7}

**Spam** = messages to people who don’t need/want product, often aggressive; ~**80–90%** of LI messages feel spammy. Qualify first.

| Pattern | Cue | Fix |
|---|---|---|
| Way too long | Pasted email wall | Short conversational IM |
| Way too short | “Hi!” only | Context + soft CTA |
| Calendar-link first | Cold Calendly | Earn meeting; ask *their* times first |
| Feature dump | About-you brochure | Them-benefit + soft Q |
| Unqualified blast | Same paste × N | Qualify first |

**Pitch vs conversation:**

| Prefer soft **them-ROI pitch** | Prefer **conversation-first** |
|---|---|
| C-level, VP, owners | Mid-management and below |
| Low LI activity, smaller network | High activity, large audience |
| Large/time-poor opportunity | Rapport-needed accounts |

Some seniors **prefer** honest pitch over “fake dance”—pitch must be about **their problem/gain**. Calendar links only after mutual interest + scheduling friction.

## ch-8 — InMail versus message {#ch-8}

| Type | Who | Access |
|---|---|---|
| Message | 1st-degree | After accept |
| InMail | Not connected | Premium / Sales Nav |

**Default:** connect → message (higher conversion). Follow ≠ message. If no accept in **7–14 days**, InMail is option.

## ch-9 — When to send a message on LinkedIn {#ch-9}

**Pitch slap** = pitch on accept (or rapport then sudden pitch).

| Segment | Wait after connect | Preconditions |
|---|---|---|
| Senior / C-level | **1–2 days** | Direct OK; less dance |
| Mid-level | **3–4 days** | After engagement |
| Large / enterprise | **1–2 weeks** | Research + account map |

## ch-10 — One size doesn’t fit all {#ch-10}

Match template to prospect, product, industry. Multi-million template is **not** mass-paste. Practice until selection is fast judgment.

## ch-11 — The seven-figure LinkedIn message {#ch-11}

**Context:** IT training → enterprise; cold call blocked; found DM on LI; minimal connect note; active → message soon.

```
Hi Sally,

Thank you for connecting! I work for a company called X, who is
one of the UK’s leading providers of IT Training. I would love to
learn a bit more about what you’re currently using for that?

Kind Regards,
Dan
```

**Mechanism:** thank → brief who-you-are → **current-state question** (not meeting ask). Opened £1.2M path. **After interest:** get email → leave LI for detail → phone → meetings. **Combo:** social created; phone/email/F2F closed.

**Process:** Find DM → connect → message → email → call → F2F → proposal → close → implement → referrals.

## ch-12 — 25 written sales message templates {#ch-12}

**Global grammar:** always **(Insert Name)**; goal = **start conversation** or **earn email** (not hard meeting); **soft words** (believe / possibly / potentially / maybe); soft CTA; pre-qualify only. LI ≠ phone: cold-call ROI often **&lt;2–3%**—platforms differ.

| # | Name | Verbatim core (compressed) | Use note |
|---|---|---|---|
| 1 | Introduction | `Thank you for connecting. I work for [company], one of the [geo] best in [product]. If I can ever help you, please do let me know.` | Planted seed; no ask; engage then later ROI |
| 2 | ROI intro | `…we help businesses [ROI] with [product]. If you ever need [product], … informal chat.` | Senior bait |
| 3 | Problem solver | `I’d love to see if we may be able to help you [problem] with [product]?` | Soft question |
| 4 | Video + link | `If you can spare three minutes, here is a quick video… similar companies achieve [ROI]… [link].` | 2–3 min; captions |
| 5 | Leadership insight | `Looking for information from [industry] leaders on [subject]. Would you contribute?` | Ego + whitepaper frame |
| 6 | Case study | `Last month we worked with [customer]. They spent X and achieved [ROI]. … may help you achieve something similar. Send a little information?` | Factual only; attach case |
| 7 | Free trial/demo | `Looking to save money [ROI] on [product]? … free trial/demo of [product].` | Low-risk try |
| 8 | Event invite | `Running an event at [location] on [date]… free ticket?` | No still opens talk; eBook fallback |
| 9 | eBook | `New eBook on latest [industry] trends. Would you like a copy?` | ~10 pages; follow up days later |
| 10 | LI recommended | `You came up as a suggestion… think we may help… send more information?` | Network **10–35/day** band |
| 11 | Cards on table | `We have [product] that does [solution]. Confident we could help achieve [ROI]. Send information?` | Honest sell, them-ROI |
| 12 | Shared group | `Both in [group]… helping similar companies with [problem/ROI]. Send info?` | Groups weak but warm |
| 13 | Mutual/referral | `[Name] suggested I pop you a message…` | **Verify** real know; LI mutual ≠ real |
| 14 | Honesty | `I’d love the opportunity to try to sell you [product]… completely honest… if not right, I’ll leave you alone. Info or call later this week?` | Honesty builds trust |
| 15 | Letter follow-up | `Just wanted to see if you got my letter in the post?` | Ultra-short multi-channel |
| 16 | Competitor | `Noticed you’re using [competitor]. Similar product, more features / competitive price. Explore with info?` | Non-aggressive options |
| 17 | ROI question | `If I could save you [ROI] on [problem], would you be interested?` | Extreme brevity bait |
| 18 | Activity | `Noticed you wrote about [subject]… great post! What do you think [Q]?` | Compliment + question |
| 19 | Profile view | `Noticed you viewed my profile… what is your company doing/using for [product]?` | Mine views daily |
| 20 | Direct profile view | `Viewed my profile today. Are you possibly looking at [product]?` | Qualified only; delayed FU |
| 21 | Engagement TY | `Thank you for liking my [content]! What were your thoughts on [topic]?` | Door-opener to intro |
| 22 | Same event | `You’re going to [event]… coffee?` or `Planning to attend [event]?` | Pre-book meetings |
| 23 | Share content | `Published [content] on your industry. Love your thoughts!` | First share must be excellent |
| 24 | Research | `Don’t want to waste your time, but I’ve researched you and [company] and believe we could help achieve [ROI]. Quick email… if interested, call?` | Research must be real |
| 25 | Missed call | `Tried to call today, you were busy… may help achieve [ROI]… more info by email?` | **Must actually call** |

## ch-13 — Top written message tips {#ch-13}

Qualify first · research always · them-centric · outside 9–5 / weekends OK for busy DMs · IM not email length · pre-send “would *I* reply?” · no-reply written → audio/video next.

## ch-14–17a — Audio voice notes {#ch-14}

**Why (2023 claim):** ~**94%** of sellers rarely send audio → pattern interrupt (era-sensitive). **Mechanics:** mobile only; **max 60s**; one note first touch. **Critical components: Tone + Relevance.** Stand/walk/smile; cold-call energy. Use for first touch, follow-up, close next-steps, account care.

**Script themes:** planted seed · profile research · verified referral · content reference · real ROI · event invite · free audit/eBook · cold-call follow-up · expert article · thoughtful gift.

**Holly Allen cadence:** reserve for **C-suite / special** prospects; structure = welcome + hyper-personalization (“show me you know me”) + subtle sell + soft CTA; name **≥2×**; don’t robot-read. Silent: wait **2d** → “Did you listen?” → wait **2d** → light self-deprecating poke. EQ filter—not all personas want audio.

## ch-18–20a — Video messages {#ch-18}

Highly effective; scary first. Closest to F2F. Optimal **60–90s**; Jarrod: **30–45s** often best; his anecdotal ~**40%** response. Prep: tidy bg, lighting, dress for meeting, **eye on camera not screen**, wipe lens, captions if mute offices.

**24h sale pattern:** notification bell → react to new-role video post in minutes → **human congrats video, zero pitch** → they reveal budget/need → schedule written → close. Speed + humanity.

**Script themes:** intro · whiteboard name · research/funding · website browse (Vidyard) · profile scroll · content · referral · expert article · similar-company insight · thoughtful gift.

| Jarrod do | Don’t |
|---|---|
| Start with **their name** | Say **your** name (UI shows it) |
| Reference profile/post | Hard pitch / cold calendar |
| Wait **~24h–1 week** after connect | Instant video if turn-off risk |
| One topic / one ask | Multi-topic monologue |
| Whiteboard their name | Untidy/noisy without captions |

Video requires connection (or InMail reply path).

## ch-21–23 — InMail {#ch-21}

Recipient knows you **paid** → pitch stigma. Most team InMails fail (**~98–99%**) when about seller, unpersonalised, or ask &gt; give. **Subject: MAKE IT ABOUT THEM.** Soft CTA matched to template.

| # | Subject pattern | Body idea |
|---|---|---|
| 1 | Include you in our article | Real article; 5–10 prospects; publish then soft next ask |
| 2 | [Name] suggested I get in touch | Name referral **2–3×**; real only |
| 3 | I think I can help you [Name] | Them-ROI + observed need + short call |
| 4 | [Co] made an extra $X | Proven peer result |
| 5 | Best [deliverable] you’ve had | Peer testimonial + soft check |
| 6 | Free [role] eBook for you | Value gated by reply |
| 7 | Short video for you [Name] | Why watch + Vidyard |
| 8 | Get [Co]’s [team] [outcome] | Problem cost → solution → info? |
| 9 | Congrats on new role | Deep personalization + soft explore |
| 10 | Noticed you’re following our co | Dig reason; careful re-engage |

## ch-24–26 — Follow-up, phone, convert {#ch-24}

**No reply ≠ wait.** Public “looking for vendor” posts draw 100+ pings—LI-only waiters lose. **Ladder:** LI → **phone** → email → letter → re-engage content → phone again. Persist without same-format spam.

Some buyers **only** buy by phone—social + phone **alongside**. Leave LI when depth rises (email/call/video/F2F). Pure-LI closes of $10–50k exist and grow; most complex B2B still exits IM. Pre-qualify makes navigation easy.

## ch-27–33 — Pipeline, profile, ops, ABCs {#ch-27}

| Pipeline failure | Rule |
|---|---|
| Pipeline size = target closes | Need **inverse close-rate** (50% close → 2× opps; 25% → 4×) |
| Denial / zombie deals | Honest purge |
| Celebrate opp, starve close | Closed is life |
| Stop prospecting when “full” | **Always Be Prospecting**; each close needs **2–3** new opps |

**LI ops tips:** Sales Nav away message · 30s cover-story video (smile first 4s) · monthly testimonial posts with **real numbers** · CRM store of prospect post links · video to open pipeline · profile link · newsletter · human photos · daily profile-view mining · banner as billboard · customer-focused summary · comment 2–3 posts/day · post daily · captions on video content · custom URL · LI in email signature.

**Profile = digital suit:** photo, banner, value headline, summary+media, activity hygiene, experience, endorsements, **recommendations process**, accomplishments. Audience = dream buyer.

**Cold calling like Blockbuster:** mono-channel refusal = obsolescence risk; phone isn’t dead—**only-phone** is.

**15 min/day:** (1) grow network ~**10** qualified adds; (2) share/create content; (3) engage prospects + industry. **ABCs:** Always Be **Connecting** · **Creating** · **Closing**.

## Anti-patterns

| Name | Detection cues | Why it kills |
|---|---|---|
| **Pitch slap** | Pitch in note or seconds after accept | Instant spam signal |
| **Calendar ego open** | Cold Calendly first | Status inversion; unearned meeting |
| **Email paste** | Multi-paragraph feature walls | Wrong medium (IM ≠ email) |
| **“Hi!” only** | Zero context | No reason to invest attention |
| **Same-format stalker** | 3–8 written “just bumping” | Trains ignore |
| **Fake personalization** | Wrong facts, generic flattery | Trust collapse |
| **Fake referral / fake call** | Claimed mutual/call that didn’t happen | Credibility nuclear |
| **About-you InMail** | Subject = your product/company | Delete/ignore reflex |
| **Mass paste templates** | Identical body × N | Spam class |
| **Hard meeting ask cold** | “Free tomorrow for 30?” first | Too sales-y for LI norms |
| **Channel purity** | Phone-only or social-only identity | Maze doors closed |
| **Pipeline denial** | Zombie opps left for comfort | Blocks real prospecting |
| **Social without close** | Endless chat, no off-platform move | Conversation ≠ revenue |
| **Non-contributing comments** | “Great post!” only | No warmth or credibility |

## Applicability & exemptions

**Applies:** B2B / complex sales where LinkedIn hosts buyers; connect or Sales Nav available; goal = conversations + pipeline.

**Weaker when:** pure PLG/self-serve; markets where WhatsApp/WeChat/email dominate; strict compliance (finance/pharma) needing legal rewrite of claims/gifts/unsolicited contact; pure job-seeker profiles.

### Era-correction (2023 book → AI-saturated inboxes)

| Book surface (2023) | Transferable mechanism | Modern quarantine / update |
|---|---|---|
| “94% don’t send audio”; “99% don’t send video” | **Pattern interrupt** via scarce format | Scarcity decays as AI/tools spread—raise **relevance** bar, not format alone |
| Soft short written templates | **Them-centric soft CTA** | AI spam floods inboxes → **specificity threshold rises** (real activity/company detail or don’t send) |
| Soft words always better | Lower threat, help framing | Still default; seniors may want crisp ROI—persona table holds |
| Bare-request default | Avoid pitchy notes | AI note spam makes **bad notes worse** |
| 5–7d wait + format rotate | Don’t same-format pester | Keep; consider multi-channel earlier under high competition |
| InMail paid = pitch stigma | Subject about them + give before ask | Stronger in AI era; must look handcrafted |
| Whiteboard / Vidyard gimmicks | Visible personalization effort | Overused → need non-generic real insight |
| 10–35 connects/day | Steady graph growth | Enforcement changes—verify current LI policy |
| Profile views / Sales Nav UI | Intent signal mining | UI shifts; principle = mine **intent signals** wherever exposed |
| “Human not automated” | Real research + real voice | **Mandatory:** if it could be ChatGPT paste, add un-Googleable detail |

**AI-era add-ons (operator extrapolation):** (1) ≥1 fact only true for this account; (2) if template survives without Layer-1 activity fact, don’t send; (3) format is table stakes—bad video still spam; (4) trust assets (recs, real ROI, content quality) matter more when text is free to generate; (5) AI enables spray—book’s qualify-first is the compliance spine.

**Contra / siblings:** ↔ `never-split-the-difference`: soft opens align with autonomy; hard close needs calibrated questions off-platform. ↔ `four-hour-workweek`: muse automation ≠ anti-spam personalization—don’t automate first-touch without per-account research. ↔ `klf-the-manual`: attention hacks differ; LI B2B rewards relevance over stunt volume.

# Literature

Imported external material, extracted notes, and third-party process references live here.

## Intent

This directory is a research library, not the source of truth for repo policy.

## How To Use

- Use these files as background input for planning and process design.
- Do not treat literature notes as live operating rules unless they have been distilled into `docs/agentic/` or a current planning doc.
- Prefer adding a small pointer from a live doc instead of copying large sections of literature into active instructions.

## Goal

**`build_nonmated_pool` seam (MCP 16756).** The earlier signature cannot enforce `exhaustive`, apply the planning ICC or recover PSU ids from faces, images and folds alone. The signature therefore takes `component_map` (image_id → psu_id, from `build_psu_components`), `exhaustive` and `planning_icc` as keywords. It raises `FrameContractError` for `exhaustive=False` and for malformed component or fold coverage. Its inputs carry no detector output, so source units stay detector-independent. The old signature is superseded only at this seam. The signatures are fixed before batch B so that each lane can run concurrently against an explicit contract (GRPH-33, practice label).

**Gallery and rotation seam (MCP 16810).** Enrolled gallery membership is a separate axis from the query fit and test folds. `build_nonmated_pool` and `build_frame` take the required keyword `enrolled_identity_ids: frozenset[str]`, with no default. Omitting it raises `TypeError` (Python's required-keyword check). A value that is `None`, not a `frozenset`, or has a non-string member raises `FrameContractError`. An explicit `frozenset()` is a declared empty gallery, not missing context, and is accepted. A named face is in a fold's pool only when its identity's fold is that fold and the identity is absent from the enrolled set. The pool depends on exhaustive GT and enrollment only, never on detections. `calibrate_tau` takes an optional `identity_folds: Mapping[str, int] | None` (S3). The scores IO always passes the full predeclared query/gallery fold map. Every used probe identity must agree with its record fold and every used top-k identity must belong to fit; a hit may belong to another fit fold. Unused test identities in the full map are allowed. Fold membership does not imply enrollment. With `identity_folds=None`, the actual producer can derive provenance from mated GT records only when they provably cover every referenced probe/gallery identity. Missing or contradictory provenance and used test identities fail closed with `CalibrationLeakError`; a complete valid actual GT context is accepted with `None`, without guessed fit membership or a blanket refusal. The full file scorer always supplies the explicit gallery map for calibration. The primary run uses one preregistered test fold, `fold_protocol.seed % fold_protocol.k` (0 for the committed values), and the other folds pool as fit. Other rotations are unsealed development diagnostics that never read the sealed frame and never feed a pooled confirmatory CV. `firbench_score_io.score_run(run_dir, *, decision, pair_scores=None) -> dict` is the scores output module; the public CLI `score_run(run_dir, *, repo_root) -> Path` is unchanged.

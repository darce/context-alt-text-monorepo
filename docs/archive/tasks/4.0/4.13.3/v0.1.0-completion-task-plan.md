## Terminology

- **Sovereign model**: Plugin reads from local projection tables at all times; backend is compute/sync peer, not runtime dependency.
- **Thumbnail deprecation**: Removal of the never-populated `thumbnail_url` column and its ~35 propagation sites across backend, plugin, and frontend.
- **Proxy-to-facade replacement**: Replacing runtime HTTP proxy dependency for cluster reads with a local service facade that reads sovereign tables only.

## Phase 0.5: Workbench Media Display -- Decouple from Sync State

**Problem**: Page 2+ of the workbench media listing shows no items. Only page 1 (which has synced cluster data) displays content. Media items should always render from the WordPress media library regardless of sync state. Syncing should only overlay cluster UUIDs and curated labels onto media that already renders.

**Architecture note**: The `/acx/v1/workbench/media` PHP endpoint already queries `wp_posts` directly via `WP_Query` (not coupled to `wp_acx_clusters`). Identity enrichment is a separate `useMediaIdentities` call overlaid client-side.

**Findings update (2026-02-20, resolved)**:
- Frontend now defaults to `status=all` and threads status through API, query keys, hooks, and page state (`apps/prototype-wp-alt-context/js/admin/api/workbenchMediaApi.ts`, `apps/prototype-wp-alt-context/js/admin/hooks/useWorkbenchMedia.ts`, `apps/prototype-wp-alt-context/js/admin/pages/WorkbenchPage.tsx`).
- Workbench UI includes a status toggle (`All media` / `Missing alt text`) so operators can intentionally scope to missing-alt items without breaking baseline pagination (`apps/prototype-wp-alt-context/js/admin/pages/workbench/MediaSelection.tsx`).
- Identity enrichment remains overlay-only: media rows render from media query data, and identity failures show a separate retry banner (`apps/prototype-wp-alt-context/js/admin/hooks/useWorkbenchMedia.ts`, `apps/prototype-wp-alt-context/js/admin/pages/workbench/MediaSelection.tsx`).
- Pagination now clamps out-of-range pages when totals shrink, preventing `Page N of M` invalid states after filter/search transitions (`apps/prototype-wp-alt-context/js/admin/pages/WorkbenchPage.tsx`, `apps/prototype-wp-alt-context/js/admin/pages/workbench/MediaSelection.tsx`).

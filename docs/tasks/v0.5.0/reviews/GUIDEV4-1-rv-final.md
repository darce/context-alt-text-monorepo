## Findings

- **RV-FINAL-01 — HIGH —** `apps/prototype-wp-alt-context/js/admin/guidedPrototype/RecordedWalkthrough.tsx:350-458`. The `scope="admin"` composition now uses the public photo flow and copy (`Two photos to check`, `Photo … of 2`, and public name/description headings); the `GuidedPrototypeGuide` stepper was also removed for both scopes. The admin route still mounts this component, while the approved screens say the admin page does not change. **Suggested fix:** keep the new photo flow and public strings behind `scope === 'public'`, retaining the admin headings and guide composition in this file.
- **RV-FINAL-02 — MEDIUM —** `apps/prototype-wp-alt-context/js/admin/guidedPrototype/RecordedWalkthrough.tsx:445-459,513-538`. Each photo shows a “Check the suggested description” placeholder under its name choices, but the actual editors are rendered later by the single `GuidedDescriptionReview`, after the photo list and provenance footer. A visitor who answers Tribeca must pass the Coachella photo and provenance before reaching Tribeca’s editor, contrary to C1/C2’s in-place review and the DDIA/latency requirement to keep the photo, decision, and next action together. **Suggested fix:** render each image’s review card inside its corresponding photo step in this file.
- **RV-FINAL-03 — MEDIUM —** `apps/prototype-wp-alt-context/js/admin/guidedPrototype/RecordedWalkthrough.tsx:187-200`. Confirming Start over resets the data but focuses `#guided-section-understand`, not the first name question required by D2. A keyboard user returns to the section heading and must navigate forward again. **Suggested fix:** call the existing first-name focus handler after confirmation, using `preventScroll`.
- **RV-FINAL-04 — MEDIUM —** `apps/prototype-wp-alt-context/js/admin/guidedPrototype/RecordedWalkthrough.tsx:310-313` and `apps/prototype-wp-alt-context/js/admin/pages/guided/GuidedPrototypeGuide.tsx:74-80`. Confirming a changed name focuses `#guided-section-review`, which is after both photos, while `focusGuidedSection` prevents scrolling. The active focus therefore leaves the visible name card for an off-screen editor section. **Suggested fix:** restore focus to the changed name radio in `RecordedWalkthrough.tsx` instead of focusing the distant review section.
- **RV-FINAL-05 — MEDIUM —** `apps/prototype-wp-alt-context/js/guide/public-guide.scss:136-149,249-269`. At 390×844 the full mobile hero stacks navigation, three wrapped copy blocks, two full-width actions, the three-item plan, and a 24px section gap before the photo count and photo title. The square image starts at or very near the bottom edge, leaving little or none of the photo visible on first paint. The new responsive E2E helper checks the horizontal gutter and dialog tile width, but never asserts the first photo’s vertical position. **Suggested fix:** reduce the mobile hero’s vertical footprint in this stylesheet and assert that the first image frame is visible within the 390×844 viewport.
